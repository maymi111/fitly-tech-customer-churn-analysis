# Fit.ly Tech Customer Churn Analysis

## Overview

This project analyzes customer churn patterns using customer account data, customer support records, and user activity data.

The goal is to identify factors associated with customer churn and provide retention recommendations.

This project was completed as part of the DataCamp Data Analyst Certification Practical Exam.

---

## Tools

Python | pandas | NumPy | matplotlib | seaborn

---

## Analysis

The analysis covered:

✓ Data cleaning and validation  
✓ Dataset integration using customer-level aggregation  
✓ Exploratory data analysis (EDA)  
✓ Business insights and recommendations

---

## Key Findings

• Overall churn rate: **28.5%**

• Free-plan customers had the highest churn rate (**40.95%**)

• Churned customers showed longer support resolution times

• Lower activity levels were associated with higher churn
